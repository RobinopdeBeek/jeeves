## What to build

AI Review runs as one SDK invocation: dual-axis Standards + Spec review (shape of `/code-review`), then immediate one-pass rework. It harvests a concise markdown overview artifact (not the Evaluation). Zero or more rework commits allowed; host verify runs again if it committed. On success, the card advances toward the Review column (Prepare Eval queued in 8.5).

Behavior is defined by [`0015-ai-review-reworks-eval-on-human-review-entry.md`](../../adr/0015-ai-review-reworks-eval-on-human-review-entry.md) (not the Project Chat ADR that also used number 0015 after #54).
